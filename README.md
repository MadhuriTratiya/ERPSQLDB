📊 ERP Database System – SQL Server
📌 Overview

This repository contains the implementation of an ERP (Enterprise Resource Planning) database system developed using Microsoft SQL Server.

The project demonstrates database design, administration, security implementation, backup management, and performance tuning techniques aligned with real-world DBA practices.

🛠 Technology Stack

Microsoft SQL Server

T-SQL

SQL Server Management Studio (SSMS)

📂 Repository Structure

ERPDB_Creation.sql – Database and schema creation

ERPInsertdata.sql – Sample data population

ERPgeneralQuery.sql – Business and reporting queries

ERMonitoringQuery.sql – Database monitoring queries

ERPPerformanceTuning.sql – Query optimization examples

ERPRoles_Security.sql – User and role management
